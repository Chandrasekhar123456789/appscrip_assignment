# Appscrip-task-chandra-sekhar (Final Vercel-ready)

Light & modern Next.js PLP demo with SSR and filters.

Features:
- Homepage shows all products by default.
- Search (queries name, category, description) — input clears after submitting to keep UI clean.
- Category pages at /categories/[category]
- Price filter and query-based filtering (?category=, ?maxPrice=, ?q=)
- Responsive light theme, SEO meta, JSON-LD
- No node_modules included. Safe to push.

Safe push & deploy instructions are in DEPLOYMENT.md
